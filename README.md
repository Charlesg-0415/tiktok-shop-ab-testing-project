# TikTok Shop A/B Testing Project

## Project Overview

This project simulates an end-to-end A/B testing workflow for an e-commerce feature rollout inspired by TikTok Shop. The goal is to evaluate whether a new seller-facing feature improves product conversion rate.

## Objective

The main business question is:

> Does the new feature improve conversion rate compared with the existing experience?

## Project Scope

This project will cover:

- Hypothesis design
- Public data collection
- Optional web scraping
- Database setup
- SQL-based data extraction
- A/B testing analysis
- Statistical inference
- Business recommendation
- Final report

## Tech Stack

- Python
- SQL
- PostgreSQL or SQLite
- pandas
- numpy
- scipy / statsmodels
- matplotlib / seaborn
- Jupyter Notebook
